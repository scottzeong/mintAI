# 인증 — 이메일 + 비밀번호

**v1.0 · 2026-07-25**

> MVP 초기에는 매직 링크만 있었다. 정식 서비스로 가면서 비밀번호 로그인을 더한다.

---

## 0. ⚠ "아이디 찾기"를 만들지 않는 이유

요구사항에 있었지만 **만들면 안 되는 기능이다.** 두 가지 이유가 있다.

### 0.1 아이디가 곧 이메일이다

별도 아이디가 없다. 로그인 식별자가 이메일 하나뿐이므로 **찾을 대상이 존재하지 않는다.**
"아이디 찾기"를 만들면 결국 *"내가 어떤 이메일로 가입했더라?"* 에 답하는 기능이 되는데,
그건 이름·전화번호 같은 **다른 개인정보를 더 받아야** 가능하다. 지금은 그걸 받지 않고,
받을 이유도 없다.

### 0.2 만들면 계정 열거 취약점이 된다

*"이 이메일이 가입돼 있나요?"* 에 정직하게 답하는 화면은 **공격자에게 회원 명부를
알려주는 창구**다. 이메일 목록을 넣고 돌리면 어떤 주소가 이 서비스를 쓰는지 전부 드러난다.

그래서 이 앱은 **가입 여부를 절대 알려주지 않는다:**

| 상황 | 화면에 뜨는 말 |
|---|---|
| 가입된 이메일로 재설정 요청 | "메일을 보냈습니다. 받은 편지함을 확인하세요." |
| **가입 안 된** 이메일로 재설정 요청 | **똑같은 문구** |
| 이미 가입된 이메일로 회원가입 | "확인 메일을 보냈습니다" (Supabase 가 응답을 흐림) |

> 실제로 메일이 오는지 여부로만 알 수 있고, 그건 **그 메일함 주인만** 알 수 있다.
> 이게 표준이다.

### 0.3 대신 두는 것

로그인 화면에 안내 한 줄을 둔다.

> *가입한 이메일이 기억나지 않으면, 쓰던 주소로 비밀번호 재설정을 요청해 보세요.
> 가입돼 있으면 메일이 도착합니다.*

**매직 링크를 남겨두는 것도 이 문제의 답이다.** 비밀번호를 잊어도 이메일만 있으면 들어온다.

---

## 1. 제공하는 것

| 기능 | 방식 |
|---|---|
| **회원가입** | 이메일 + 비밀번호. 확인 메일 클릭 후 활성화 |
| **로그인** | 이메일 + 비밀번호 |
| **매직 링크 로그인** | 비밀번호 없이. **없애지 않는다** (§0.3) |
| **비밀번호 재설정** | 메일 링크 → `/auth/reset` 에서 새 비밀번호 |
| ~~아이디 찾기~~ | **만들지 않는다** (§0) |

---

## 2. 비밀번호 재설정 흐름

```
로그인 화면 → "비밀번호를 잊으셨나요"
  → resetPasswordForEmail(email, { redirectTo: /auth/reset })
  → 메일 도착 → 링크 클릭
  → /auth/reset 에 복구 세션이 붙은 채로 착지
  → 새 비밀번호 입력 → updateUser({ password })
  → 홈으로
```

**`/auth/reset` 은 별도 라우트여야 한다.** 앱 본체는 `AuthGate` 가 감싸고 있어서
로그인하지 않으면 아무것도 못 보는데, 재설정 링크로 들어온 사람은 아직 "로그인한 것도
안 한 것도 아닌" 상태다. 같은 화면에 두면 게이트에 막힌다.

---

## 3. 비밀번호 정책

| 항목 | 값 | 이유 |
|---|---|---|
| 최소 길이 | **8자** | Supabase 기본은 6자다. 6자는 지금 기준으로 짧다 |
| 복잡도 규칙 | **없음** | 특수문자 강제는 `Password1!` 같은 예측 가능한 비밀번호를 만든다. 길이가 더 효과적이다 |
| 유출 비밀번호 차단 | **Supabase 설정에서 켠다** | 이미 유출된 비밀번호를 거른다. 규칙보다 실효가 크다 |

---

## 4. Supabase 설정 (코드 밖)

1. **Authentication → Providers → Email** — `Enable` 확인
2. **Confirm email** — 켠다. 끄면 남의 이메일로 가입할 수 있다
3. **Authentication → Policies → Minimum password length** — `8`
4. **Leaked password protection** — 켠다
5. **URL Configuration → Redirect URLs** 에 재설정 착지점 추가:
   ```
   https://mintai.kr/auth/reset
   https://<프로젝트>.vercel.app/auth/reset
   http://localhost:3000/auth/reset
   ```
   > 기존 `/**` 패턴이 있으면 이미 포함되지만, 명시해 두면 나중에 패턴을 좁혀도 안 깨진다.

---

## 5. 기존 사용자

매직 링크로 가입한 계정에는 **비밀번호가 없다.** 그대로 두면 비밀번호 로그인이 안 된다.

두 가지 길이 있고 둘 다 열어둔다:

- 매직 링크로 로그인 → 계속 그렇게 쓴다
- "비밀번호를 잊으셨나요" 로 **비밀번호를 처음 설정**한다 (같은 흐름이 그대로 쓰인다)
