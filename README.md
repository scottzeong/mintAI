# mintAI — Scriptorium

> 저술을 위한 개인 지식 정제 시스템

## 한 줄 정의

흩어진 생각을 AI 리서치와 **인간의 요약**을 거쳐 학술 수준으로 검증된 지식 카드로 정제하고,
그 카드만을 재료로 **책을 완성**하는 개인용 저술 시스템.

## 핵심 원칙

1. **AI가 쓴 문장은 DB에 남지 않는다** — 영구 저장되는 산문은 100% 인간이 타이핑한 것
2. **단, 사실 데이터(출처·인용원문)는 승계한다**
3. **집필은 종착점이 아니라 조사의 트리거다** — 파이프라인은 루프
4. **생성 AI는 Library 밖의 지식을 사용할 수 없다**
5. **한 권의 책 = 하나의 목차 = 하나의 목소리**
